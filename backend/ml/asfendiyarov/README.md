# Asfendiyarov De-Identified Dataset

This folder contains a de-identified numeric clinical feature dataset authorized for hackathon research/demo use.

- Source: Asfendiyarov University hackathon dataset.
- Direct patient identifiers are not included in this repository copy.
- The original date column `b_dob` was removed before committing.
- Use only for aggregate analysis and model demonstration.
- Delete after the event if required by the data owner.
